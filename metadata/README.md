# Metadata

This directory contains non-identifiable metadata and variable-selection files used to define the analysis feature sets.

Included files:

- `lit_reduced_variable_decisions.csv`: Literature-aligned reduced predictor decisions.
- `literature_aligned_two_model_variable_plan.csv`: Variable plan separating domestic and shared-feature model tracks.
- `yrbss2023_variable_metadata.csv`: YRBSS 2023 column metadata used for cross-national variable harmonization.

Raw survey data and participant-level analytic datasets are not stored in this repository.
